# Ender-3 モニター

この PC につないだ Ender-3（USB シリアル）と USB カメラ（Logi C270）を使って、スマホのブラウザから

- カメラ映像を見る
- ノズル／ベッド温度と SD 印刷の進み具合を見る
- **一時停止 / 再開 / 中止して冷却 / 緊急停止** を送る

ための小さな Web サーバーです。中身は `printer_monitor.py`（サーバー）と `index.html`（画面）の2ファイルだけです。

## 起動

```powershell
# 自分の PC だけで試す（127.0.0.1:8090、トークンなし）
uv run printer_monitor.py

# スマホから使う（0.0.0.0:8090、トークンあり）
.\start.ps1
```

`start.ps1` は初回にランダムなトークンを `token.txt` に作ります。スマホで最初に

```
http://<この PC のアドレス>:8090/?token=<token.txt の中身>
```

を一度開けば、トークンは Cookie に保存されて URL からは消えます。以降は `http://<アドレス>:8090/` だけで開けます。ホーム画面に追加すると、アプリのように使えます。

初回起動時に Windows ファイアウォールの確認が出たら、「プライベートネットワーク」を許可してください。

## 外出先から見る（Tailscale）

1. この PC とスマホの両方に Tailscale を入れて、同じアカウントでログインする
2. この PC の Tailscale アドレス（`100.x.y.z`、または `<PC名>.<tailnet>.ts.net`）を確認する
3. スマホで `http://100.x.y.z:8090/?token=...` を開く

ポート開放やルーターの設定は不要です。インターネットに公開されるわけではなく、Tailscale につないだ自分の端末からしかアクセスできません。

## 大事な注意

- **印刷を始める前にサーバーを起動しておく。** サーバーは COM7 を開いたまま持ち続けます。Ender-3 は COM ポートを開いた瞬間に基板がリセットされることがあり、SD 印刷中に起きるとその印刷は止まります（今の設定では DTR を下げてリセットを避けていて、手元の確認ではリセットは起きませんでした）。
- **USB が抜けても自動では再接続しない。** 再接続でリセットがかかる可能性があるからです。画面に「プリンターに再接続」ボタンが出るので、印刷していないことを確認してから押してください。
- **一時停止中もノズルは熱いまま。** 長く止めておくなら「中止して冷却」を使ってください。
- **緊急停止（M112）の後は、本体のリセットか電源の入れ直しが必要です。**
- 停止系のコマンドは **SD カードからの印刷** を前提にしています（`M25` / `M24` / `M524`）。
- Ender-3 にはライトがないので、夜は映像が暗くなります。必要なら LED を付けてください。
- カメラは、ベッドとノズルが映る位置（正面か斜め前、ベッドと同じくらいの高さ）に置いてください。

## PC のつけっぱなし設定

- 設定 → システム → 電源 → 画面とスリープ：「接続時にスリープ」を **なし** にする
- コントロールパネル → 電源オプション → 「カバーを閉じたときの動作」：電源接続時を **何もしない** にする

## ログオン時に自動で起動する（任意）

タスク スケジューラで「ログオン時」をトリガーにして、次を実行するタスクを作ります。

```
powershell.exe -ExecutionPolicy Bypass -File <このフォルダーのパス>\start.ps1
```

## 設定（環境変数）

| 変数 | 既定値 | 内容 |
|---|---|---|
| `PM_SERIAL` | `COM7` | プリンターの COM ポート |
| `PM_BAUD` | `115200` | ボーレート |
| `PM_CAMERA` | `0` | カメラ番号 |
| `PM_HOST` | `127.0.0.1` | 待ち受けアドレス（`start.ps1` では `0.0.0.0`） |
| `PM_PORT` | `8090` | ポート |
| `PM_FPS` | `5` | 配信のフレームレート |
| `PM_TOKEN` | なし | 設定するとトークンが必須になる |
